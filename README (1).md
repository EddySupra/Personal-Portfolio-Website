# Eduardo Casas-Gabirio - Personal Portfolio Website

This is a fully responsive and animated personal portfolio website built using **React**, **Tailwind CSS**, and **Framer Motion**. The project showcases Eduardo Casas-Gabirio's professional background, technical skills, personal projects, and contact information.

## 🔧 Technologies Used
- **React**: Component-based JavaScript UI library
- **Tailwind CSS**: Utility-first CSS framework
- **Framer Motion**: Animation and transitions
- **React Router DOM**: Client-side routing
- **Formspree**: Contact form handling
- **Firebase / Node.js / MongoDB**: Backends used in featured projects

## 📁 Project Structure
- `/src`: React components including `App.jsx`, pages like Home, About, Projects, Skills, Contact.
- `/public`: Static assets like avatar image and project screenshots.
- `tailwind.config.js` and `postcss.config.js`: Tailwind CSS setup.

## 🚀 Getting Started Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/your-username/portfolio-site.git
   cd portfolio-site
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm start
   ```

4. Build for production:
   ```bash
   npm run build
   ```

## 🌐 Deployment

This site is optimized for deployment via [Netlify](https://www.netlify.com/). Be sure to include a `_redirects` file in the `public/` directory with this content:

```
/*    /index.html   200
```
