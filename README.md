# My Portfolio

## Overview
A personal portfolio website built with React, Tailwind CSS, Framer Motion, and React Router.

## Setup
1. Clone the repository
2. `npm install`
3. `npm start`

## Build
`npm run build`

## Deployment
- Deploy `build/` folder to Netlify, Vercel, GitHub Pages, etc.

## Pages
- **Home:** Intro & tagline
- **About:** Bio & résumé
- **Projects:** Showcase
- **Skills:** Skill categories
- **Contact:** Form & social links
